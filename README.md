# Entorno virtual 3D

Escena 3D interactiva hecha con React y Three.js, empaquetada con Vite.

## Requisitos

- Node.js

## Uso

```bash
npm install
npm run dev
```

Para generar la versión de producción: `npm run build` (se crea en `dist/`).
